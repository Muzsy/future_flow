# Product dokumentáció

Itt találhatók a kanonikus termékdöntések: termékdefiníció, scope, monetizáció, privacy-termékszabályok és release/beta scope.

Szabályok:

- a kívánt felhasználói/üzleti viselkedést írja le, nem az implementációs naplót;
- egy témához lehetőleg egy kanonikus dokumentum tartozzon;
- tartós döntés indoklása ADR-ben legyen;
- mérési riport és lezárt kísérlet ne ide kerüljön.

Kanonikus fájlok a konszolidáció során: `PRODUCT_HU.md`, `MONETIZATION_HU.md`, valamint szükség szerint privacy/beta scope dokumentumok.
