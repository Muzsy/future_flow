# Architecture Decision Records

Ez a könyvtár az Alterward tartós architekturális és termék-technikai döntéseit tartalmazza.

Fájlnév:

`ADR-NNN-short-title.md`

Minden ADR minimum:

- Status
- Date
- Context
- Decision
- Consequences
- Alternatives considered
- Related docs/code

Elfogadott ADR-t ne írj át úgy, mintha a múltbeli döntés más lett volna. Lényegi változásnál új ADR készüljön, amely `supersedes` kapcsolattal leváltja a régit.

ADR nem tasklista, nem státuszjelentés és nem implementation report.
