# Feature dokumentáció

Feature-specifikációk könyvtára. Egy feature kanonikus dokumentuma mondja meg a felhasználói viselkedést, jogosultságokat, lifecycle-t, fontos contractokat és a még nem implementált részeket.

Javasolt szerkezet feature-enként:

- cél és scope;
- fogalmak/invariánsok;
- user flow;
- entitlement/governance;
- adat- és AI-határok;
- privacy/security követelmények;
- implementált vs. nem implementált állapot;
- kapcsolódó ADR-ek és kódhelyek.

Lezárt fázisriportok nem feature-specifikációk; konszolidáció után archive-ba kerülnek.
