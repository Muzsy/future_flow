# alterward — English closed-beta reading catalog

Fifteen fictional AI-generated lives, each with three six-month chapters, and five independently reviewed starting Scenarios. This is the approved staging reading copy. The website and beta spending are not activated by these documents. Original Sonnet audits, full content scans and separate editorial decisions are retained privately. Modified public copies receive a separate Claude audit; one bounded copy check uses Haiku 4.5. Preserved negative audits have individual editorial dispositions rather than being reported as passed.
