# Operations dokumentáció

Aktív operátori és fejlesztési runbookok helye.

Ide tartozik:

- development/setup;
- testing és release gate;
- deployment;
- beta activation/operation;
- backup;
- recovery;
- security operations és monitoring.

Egy runbook legyen végrehajtható: precondition → lépések → verification → failure/rollback → postcondition.

Az egyszeri végrehajtási riport nem runbook; az történeti anyag.
