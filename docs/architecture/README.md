# Architecture dokumentáció

Itt találhatók a rendszer tartós technikai határai és invariánsai: komponensek, adatfolyamok, adatmodell, AI pipeline, security/privacy technikai modell.

Szabályok:

- a kódhoz kötődő tartós szerkezetet írja le;
- endpoint- vagy implementation log helyett rendszerhatárokat dokumentál;
- fontos döntési indok külön ADR-ben legyen;
- a dokumentum ne másolja teljes egészében a contract/schema tartalmát, hanem hivatkozzon rá.

Kanonikus célfájlok: `ARCHITECTURE_HU.md`, `DATA_MODEL_HU.md`, `AI_PIPELINE_HU.md`, `SECURITY_MODEL_HU.md`.
